# CRM-onboarding — Klanten & Taken

Presentatie voor het onboarden van collega's op het A-Journal wholesale-CRM
(`ajournal-crm`), gericht op de schermen **Klanten** en **Taken**: waarom we het
CRM hebben en hoe het dagelijks werkt.

- **Live:** https://a-journal.github.io/crm-onboarding/
- Eén bestand: `index.html` (geen build, geen afhankelijkheden behalve Google Fonts).
- Navigeren met pijltjestoetsen, scrollen of de knoppen rechtsonder; printbaar (één slide per pagina).
- Alle klantnamen, nummers en bedragen in de voorbeeldschermen zijn **fictief**.
- Pagina is `noindex`; de repo is publiek omdat GitHub Pages dat op het gratis org-plan vereist.

Hoort bij CRM-versie 0.40 (oktober 2026). Bij wijzigingen in de schermen: pas de
betreffende slide aan en push naar `main`; Pages publiceert automatisch.
